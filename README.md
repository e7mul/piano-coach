# Piano Coach

A practice app for a digital piano over USB/Bluetooth MIDI: falling notes, live feedback on pitch, timing and loudness, an adaptive path built around River Flows in You, and an optional coach chat.

Open the GitHub Pages site in a Chromium-based browser (Vanadium, Brave, Chrome), allow MIDI, and install it from the browser menu. Progress stays in the browser; use Export/Import progress to move it between devices.

When `index.html` changes, bump `VERSION` in `sw.js` so installed copies update.
